Crystal cell and periodic boundaries

Choose the lattice metric (crystal system), then enter a, b, c in Å and α, β, γ in degrees. Crystal habit alone does not determine the unit cell. Coordinates stay Cartesian: a along x, b in xy, c with positive z. No symmetry expansion or rescaling is performed.

The same atom keeps the same number everywhere: MONET ID (viewer, extraction, QM inputs) = ASE index + 1 in the original file = MDAnalysis id (use id 5 7 in selections). Elements and first-frame coordinates are compared between the three programs; residues and molecules come from the topology or, for XYZ files, from the same bonded molecules used by the ASE molecule picker.

Bonds, angles and dihedrals are found from the first-frame connectivity (bond cutoff of the viewer), restricted to the atoms entered. For each item: mean, SD (circular for dihedrals), extremes, 5–95 % range, linear trend with its error and R², drift between the two halves, the dominant oscillation frequency and a trend test on five block averages. Torsion about the middle bond, in ASE's 0–360° convention. Periodic-image correction is optional in Crystal cell. Collinear groups have undefined dihedrals.

Folded modes map torsions modulo 180°, so opposite orientations become equivalent: [0°, 180°) keeps values near 90° continuous, [−90°, +90°) keeps values near 0° continuous. When a value crosses the range edge, the trace continues from the opposite edge. Change the range, then recompute.

Normalised g(r) with minimum-image distances; needs a periodic cell. Rmax is limited to half the smallest cell width. n(r) is the running coordination number.

Radial distribution function

Positions are unwrapped when a periodic cell is present; MSD is averaged over all time origins; D = slope / 6 from a linear fit in the chosen window.

Mean-square displacement vs lag time

Fourier transform of finite-difference velocities (Hann window), normalised to unit area. Save frames every MD step (or few steps) for accurate high frequencies; the Nyquist limit is shown after the calculation.

Download uncorrelated trajectory

Dihedrals are unwrapped across 0/360° (or 0/180° when folded) before the linear correlation; the circular mode uses z = e^{iθ} with its mean removed, so both decay to zero. The default lag range is half of the run: longer lags average over too few time origins. τ gives the decorrelation time: sampling configurations every ≥ τ yields statistically independent structures.
